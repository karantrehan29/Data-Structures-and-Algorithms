# Week 2 — Question 5: 3Sum

## Problem

Given an integer array `nums`, return every unique triplet of values whose sum is zero. Do not include the same triplet more than once. The triplets may be returned in any order.

## Examples

```text
Input:  nums = [-1, 0, 1, 2, -1, -4]
Output: [[-1, -1, 2], [-1, 0, 1]]
```

```text
Input:  nums = [0, 1, 1]
Output: []
```

```text
Input:  nums = [0, 0, 0]
Output: [[0, 0, 0]]
```

## Constraints

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`
